# 🎓 AprendeMais - Plataforma de Educação e Oportunidades

> Projeto Prático da disciplina de **Programação Web Front-end** focado no **ODS 4 (Educação de Qualidade)** da ONU.

---

## 📌 Sobre o Projeto

O **AprendeMais** é uma solução web desenvolvida para conectar pessoas a oportunidades de aprendizado gratuito e desenvolvimento pessoal/profissional. O objetivo principal é promover uma educação inclusiva, equitativa e de qualidade, facilitando o acesso de jovens e adultos a conteúdos relevantes para o mercado de trabalho.

## 🚀 Funcionalidades e Telas

1. **Tela de Login e Cadastro (`index.html`):**
   * Formulário de cadastro completo com 5 campos (`Nome`, `E-mail`, `Telefone`, `Escolaridade` e `Senha`).
   * Formulário de login funcional redirecionando para a aplicação principal.
   * Design responsivo e amigável.

2. **Página Principal (`principal.html`):**
   * **Banner Hero** com mensagem de impacto sobre o ODS 4.
   * **Seção Sobre:** Informações detalhadas da proposta da plataforma.
   * **Seção de Cursos/Oportunidades:** Cards estruturados de cursos profissionalizantes.
   * **Menu de Navegação:** Âncoras internas e opção de Logout.
   * **Rodapé:** Direitos autorais e links para os currículos da equipe.

3. **Currículo Vitae (`vitae.html`):**
   * Página individual de apresentação dos integrantes com foto, histórico profissional, acadêmico e link para o LinkedIn.
